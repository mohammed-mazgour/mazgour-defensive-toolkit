# Mazgour Defensive Toolkit

Ten offline-first Python tools for local defensive security reviews. They inspect files and configurations you own or are authorized to assess; they do not exploit targets, brute-force accounts, persist, or send data over the network.

## Download

Download [Mazgour-Defensive-Toolkit.zip](Mazgour-Defensive-Toolkit.zip) and extract it. The archive contains ten standalone tools, individual guides, synthetic examples, a start guide, and the MIT license. Python 3.10+ is required; no third-party packages are needed.

## Included tools

SecretSentry · FileIntegrity · ConfigGuardian · LogTriage · HeaderReview · SBOMScout · BackupVerifier · PermissionLens · PrivacyMap · WebRiskLint.

Each tool has a separate folder and README inside the archive. Findings are heuristics for human review, not proof that a system is secure. Read the responsible-use notes before running them.
