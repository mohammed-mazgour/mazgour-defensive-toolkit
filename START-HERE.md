# Start here

1. Install Python 3.10 or newer from the official Python website.
2. Download this repository as a ZIP and extract it.
3. Open the folder in VS Code or a terminal.
4. Open a tool's own README and run its example with `python`.
5. Start with the synthetic inputs in `examples/` to learn the output.

No dependencies need to be installed. The tools do not perform network requests. Their reports may contain local filenames, usernames, IP addresses, or configuration details; keep those reports private unless you have reviewed them for sharing.
